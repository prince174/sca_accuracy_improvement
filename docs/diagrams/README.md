# Схема работы системы

- `system-workflow.html` — автономная интерактивная схема: нажмите узел для пояснения.
  Режимы «Без модели» и «Модель + валидатор» соответствуют реализации. API v2 по умолчанию использует второй.
  Откройте скачанный HTML в браузере; GitHub не исполняет HTML-файлы репозитория.

- `system-workflow.drawio` — исходная редактируемая схема draw.io / diagrams.net.
- `system-workflow.png` — экспорт для отображения в основном README.

В схеме показаны удалённые входы, HTTP API v2, отдельные каталоги образа и исходников,
сопоставление с SBOM, дополнительный анализ Java, опциональная модель и выдача
результатов внешнему pipeline. Загрузку в Dependency-Track выполняет внешний pipeline.

Редактирование: откройте `.drawio` в draw.io Desktop или diagrams.net.
После изменения экспортируйте PNG с масштабом 100% и белым фоном, заменив
`system-workflow.png`, чтобы превью в README соответствовало исходнику.
